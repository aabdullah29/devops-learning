# Replit Commands

## Running projects
```bash
npm install
npm run dev
python app.py
```

## Git and GitHub integration
```bash
git status
git add .
git commit -m "Update project"
git push origin main
```

## Common workflow
- Open a Replit project
- Connect it to a GitHub repository
- Run the app in the browser or terminal
- Commit and push updates

## Deployment basics
- Use Replit runs for local execution
- Deploy app to a live Replit environment
- Share project links and public access

## Notes
- Replit is useful for quick experiments and app demos
- It simplifies project hosting and collaboration
- It can work well with Git and GitHub for version control
