# Replit

Replit is a cloud-based development environment where I can write, run, and deploy code from a browser.

## Important note

**Important:** Replit's CLI commands/features can change, so don't blindly add commands just because they look similar to Git. For your learning repo, document the Replit commands you actually use.

## Core learning rule
For every Replit command or workflow step, understand:
- What is it?
- Why do I need it?
- What does it change?
- How do I verify it?

Example:

```bash
replit run
```

Don't only memorize it. Understand:

> `replit` → the Replit CLI  
> `run` → runs the current project  
> It executes the project in the Replit environment

## Replit + GitHub

Replit can work with Git/GitHub.

Basic workflow:
1. Create/open project in Replit
2. Write code
3. Test/run the application
4. Commit changes with Git
5. Push changes to GitHub
