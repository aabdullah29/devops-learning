# Replit Notes

## What Replit is
Replit is an online IDE and hosting platform that makes it easy to create, run, and share projects directly from the browser.

## Core ideas
- Manage projects in one place
- Run code without a local setup
- Connect to GitHub repositories
- Deploy apps quickly for demos or learning

## Useful workflow
1. Create a project
2. Write code
3. Run the application
4. Commit changes to Git
5. Push to GitHub
6. Deploy or share the project

## Good for learning
- Quick web app projects
- Backend experiments
- Small deployment examples
- Git/GitHub practice in a browser-based environment
