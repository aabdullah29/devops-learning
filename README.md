# DevOps Learning

This repository is organized as a structured learning path for core DevOps topics, starting with Linux, Git, GitHub, and Replit before moving into cloud, containers, and infrastructure automation.

## 1. Linux
- Files & directories
- Permissions & ownership
- Users & groups
- Processes
- Services / systemd
- Packages
- Networking
- SSH
- Disk / memory / CPU
- Logs
- Bash basics

## 2. Git
- init / clone
- status
- add / commit
- log / diff
- branch
- merge
- stash
- reset / revert
- .gitignore

## 3. GitHub
- repositories
- push / pull
- branches
- Pull Requests
- Issues
- README.md
- GitHub Actions (later)

## 4. Replit
- Projects
- Git/GitHub integration
- Running applications
- Deployment basics

## 5. Bucket (cloud)
- AWS S3 / cloud storage
- Learn it after Linux + Git basics

## 6. Advanced path
- Docker
- CI/CD
- AWS
- Kubernetes
- Terraform
- Monitoring

## Repository goals
- Build a practical command reference for Linux and Git
- Learn collaboration with GitHub
- Practice deployment and project hosting with Replit
- Prepare for cloud, container, and infrastructure topics

## Suggested order
1. Linux fundamentals
2. Git basics and version control
3. GitHub workflows and collaboration
4. Replit projects and deployment basics
5. Cloud storage fundamentals
6. Docker, CI/CD, AWS, Kubernetes, Terraform, and Monitoring

### Learning order

For Replit, don't spend too much time on it yet:

```text
Linux  ↓ Git  ↓ GitHub  ↓ Replit  ↓ Bash scripting  ↓ Docker  ↓ CI/CD
```
