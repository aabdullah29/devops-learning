# GitHub Notes

## Core concepts
- GitHub hosts Git repositories online
- Repositories store project code and files
- Branches are used for parallel work
- Pull requests are used for review and merging
- Issues help track tasks and bugs
- README files explain the project clearly

## Workflow
1. Create or clone a repository
2. Make changes locally
3. Commit and push to a branch
4. Open a pull request
5. Review, discuss, and merge

## Later learning
- GitHub Actions for automation
- Secrets and environment variables
- CI/CD pipelines
- Branch protection rules
